Privacy Policy

Archive Manager+

Last updated: November 8, 2026

Our Privacy Commitment

Archive Manager+ is designed to manage archive files locally on your Android device. Based on the current application implementation, archive contents are not uploaded to our servers.

1. Introduction

Welcome to Archive Manager+ ("the App"). This Privacy Policy explains how information is accessed, processed, stored, and protected when you use the App.

Archive Manager+ is an Android utility application that helps users manage compressed files, inspect archives, create archives, and extract supported archive formats.

2. Information We Access

The App may access files and documents that you explicitly select using Android's system file picker.

Depending on the operation requested, this may include:

  • Archive file names and metadata
  • Contents of selected archive files
  • Selected document references
  • Files selected for archive creation
  • Files and folders chosen for extraction

These files are accessed to perform user-requested archive operations.

3. How Information Is Used

Selected files are processed to provide application features, including:

  • Opening and inspecting archive files
  • Creating compressed archives
  • Extracting supported archive formats
  • Displaying archive information
  • Maintaining references to selected files

File contents are processed locally on the device for these purposes.

4. Data Collection and Sharing

The current version of Archive Manager+ is designed to operate without user accounts, advertising SDKs, or analytics services.

Based on the reviewed implementation, the App does not intentionally transmit selected archive contents, personal files, or document information to the developer or third-party servers.

We do not sell user information.

5. Local Storage and Retention

Archive Manager+ may temporarily copy selected files into application cache storage to complete archive operations.

The App may also save references to previously selected documents in local application preferences.

Temporary processing files are intended to be removed after their associated operations. Saved document references may remain until removed through the App, cleared through Android settings, or deleted when the App is uninstalled.

Archive files and extracted files saved outside the App's private storage may remain on the device until you delete them.

6. File Access and Permissions

The App uses Android's system file selection mechanisms to let users choose files for processing.

Where supported, Android may allow the App to retain access to selected document references for future use.

Users can manage or revoke applicable access through Android settings or by removing files from the App's library, where supported.

7. Third-Party Software Libraries

Archive Manager+ uses software libraries to support archive compression, extraction, and Android interface functionality.

These may include Apache Commons Compress, XZ for Java, Junrar, and AndroidX libraries.

The inclusion of these libraries does not by itself mean that user files are transmitted to external services.

8. Security

We aim to minimize unnecessary access to user information by performing archive operations locally and using Android's file access mechanisms.

However, no software system can guarantee absolute security. Users should exercise caution when opening archives from unknown or untrusted sources.

9. Children's Privacy

Archive Manager+ is a general-purpose file utility and is not specifically designed for children.

The App does not intentionally request personal information from children.

10. Your Choices

You can control which files are selected for processing and where supported, remove saved document references.

You may clear the App's local data using Android settings or uninstall the App to remove its private application data.

11. Changes to This Privacy Policy

We may update this Privacy Policy when application functionality, data handling practices, or applicable requirements change.

Updated versions will be published on this page with a revised "Last updated" date.
