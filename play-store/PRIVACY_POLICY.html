Archive Manager+ Privacy Policy

Last updated: 25 October 2026

This is a draft policy. The publisher must review it against the final app behavior and replace the contact placeholder before publishing.

Information and files

Archive Manager+ uses Android's system document picker so you can select files. The current prototype processes a selected ZIP file locally to display entry names. It does not intentionally upload selected files to a server. Temporary inspection copies are stored in the app cache and are deleted after inspection completes.

Data collection and sharing

The current prototype has no account system or analytics integration. This statement must be updated if the app adds analytics, ads, crash reporting, cloud backup, or any other data collection or sharing.

Permissions and control

The app relies on user-selected documents through Android's Storage Access Framework and does not request broad access to shared storage. You can remove an item from the in-session list; that does not delete the original document.

Children

The app is a general file utility and is not designed specifically for children.

Security and changes

We may update this policy when app features or data practices change.
